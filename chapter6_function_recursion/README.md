# Chapter 6: Functions and Recursion

This chapter covers Python functions and recursion through practical programming exercises. The programs focus on function parameters, return values, base cases, and recursive problem-solving.

## Practice Programs

1. **Greatest of Three Numbers** — Find the greatest among three numbers using a function.
2. **Celsius to Fahrenheit** — Convert temperature from Celsius to Fahrenheit using a function.
3. **Factorial using Recursion** — Calculate the factorial of a number using recursion.
4. **Sum of Natural Numbers using Recursion** — Calculate the sum of the first N natural numbers recursively.
5. **Fibonacci using Recursion** — Find the nth Fibonacci number using recursion.
6. **Sum of Digits using Recursion** — Calculate the sum of digits of a number recursively.
7. **Power of a Number using Recursion** — Calculate a number raised to a power without using the `**` operator.
8. **GCD using a Function** — Find the Greatest Common Divisor (GCD) of two numbers using a function.

## Concepts Covered

- Defining functions using `def`
- Function parameters and arguments
- Returning values using `return`
- Calling functions
- Recursive functions
- Base cases
- Recursive calls
- Number manipulation using `%` and `//`
- Problem-solving using functions and recursion

## Learning Outcome

Practiced creating reusable functions and learned how recursive functions solve problems by breaking them into smaller subproblems until a base condition is reached.
