# Chapter 6: Functions and Recursion

This chapter covers Python functions and recursion through practical programming exercises.

## Practice Programs

1. **Greatest of Three Numbers** — Find the greatest among three numbers using a function.
2. **Celsius to Fahrenheit** — Convert temperature from Celsius to Fahrenheit using a function.

## Concepts Covered

- Defining functions using `def`
- Function parameters and arguments
- Returning values using `return`
- Calling functions
- Taking user input and passing it to functions
