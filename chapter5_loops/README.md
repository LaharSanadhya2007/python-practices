# Chapter 5: Loops in Python

This chapter covers Python loops through practical programming exercises involving number operations, mathematical problems, and pattern printing.

## Practice Programs

1. **`01table_by_for.py`** — Print a multiplication table using a `for` loop.
2. **`02table_by_while.py`** — Print a multiplication table using a `while` loop.
3. **`03sum_natural_numbers.py`** — Calculate the sum of natural numbers up to N.
4. **`04factorial.py`** — Calculate the factorial of a number.
5. **`05sum_of_digits.py`** — Calculate the sum of the digits of a number.
6. **`06reverse_number.py`** — Reverse a number using a loop.
7. **`07palindrome_number.py`** — Check whether a number is a palindrome.
8. **`08prime_number.py`** — Check whether a number is prime.
9. **`09fibonacci_series.py`** — Generate the Fibonacci series.
10. **`10count_digits.py`** — Count the digits in a number.
11. **`11find_gcd.py`** — Find the Greatest Common Divisor (GCD) of two numbers.
12. **`12pattern_triangle.py`** — Print a star triangle pattern.
13. **`13pattern_number.py`** — Print a number triangle pattern.
14. **`14break.py`** — Practice loop termination using `break`.
15. **`15armstrong_number.py`** — Check whether a number is an Armstrong number.
16. **`16continue.py`** — Skip selected iterations using `continue`.

## Concepts Covered

- `for` and `while` loops
- The `range()` function
- Loop control statements: `break` and `continue`
- Nested loops and pattern printing
- Modulo (`%`) and floor division (`//`)
- Digit extraction and number manipulation
- Mathematical problem-solving using loops

## Learning Outcome

Practiced iteration, loop control, number-based problems, and nested-loop patterns through hands-on Python programs.
