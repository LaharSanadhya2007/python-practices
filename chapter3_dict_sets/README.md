# Chapter 3 — Dictionaries & Sets

This chapter covers the basics of **Dictionaries and Sets in Python** through practical problem-solving.

## Topics Covered

- Dictionary creation and accessing values
- Updating dictionary values
- Checking dictionary keys
- Set intersection
- Set difference
- Symmetric difference
- Removing duplicates using sets
- Taking input from the user

## Practice Programs

1. **Student Marks Lookup** — Access dictionary values using a key.
2. **Update Dictionary Value** — Update a value in a dictionary using user input.
3. **Common Elements** — Find common elements between two sets.
4. **Remove Duplicates** — Remove duplicate values from a list using a set.
5. **Unique Elements Between Sets** — Find elements that are not common between two sets.
6. **Check Dictionary Key** — Check whether a given key exists in a dictionary.
