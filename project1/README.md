# Snake Water Gun Game 🐍💧🔫

A simple command-line Snake, Water, and Gun game built using Python.

The player competes against the computer, which randomly selects Snake, Water, or Gun.

## Game Rules

- Snake beats Water
- Water beats Gun
- Gun beats Snake
- Same choices result in a draw

## How to Play

Enter one of the following choices:

- `s` — Snake
- `w` — Water
- `g` — Gun

The computer randomly selects its choice, and the program determines the winner.

## Concepts Used

- Python dictionaries
- Conditional statements
- User input
- `random` module
- `random.choice()`
- f-strings
- Basic game logic

## Run the Program

```bash
python snake_water_gun.py
