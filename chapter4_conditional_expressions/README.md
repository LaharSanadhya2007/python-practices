# Chapter 4 — Conditional Expressions

This chapter focuses on using **conditional expressions** in Python to make simple decisions in a single line.

## Topics Covered

- Conditional expressions
- `if-else`
- Taking input using `input()`
- Comparison operators
- Even and odd numbers
- Positive, negative and zero
- Comparing two numbers
- Pass or fail conditions
- Age-based conditions

## Practice Programs

1. **Even or Odd** — Check whether a number is even or odd.
2. **Positive, Negative or Zero** — Identify the type of a number.
3. **Greater Number** — Find the greater of two numbers.
4. **Pass or Fail** — Check whether marks are enough to pass.
5. **Adult or Minor** — Determine whether a person is an adult or minor.
