# Chapter 7: File I/O in Python

This chapter covers working with files in Python through practical programs involving reading, writing, updating, searching, and modifying file content.

## Practice Programs

1. **Word Search in File** — Check whether the word `twinkle` is present in a text file.
2. **High Score Tracker** — Generate a random score, read the previous high score from a file, and update it when a new high score is achieved.
3. **Multiplication Table File Generator** — Generate multiplication tables from 15 to 20 and save each table in a separate text file.
4. **Single Word Censor** — Replace the word `donkey` with `######` in a text file.
5. **Multiple Word Censor** — Replace multiple specified words with `#` characters while preserving their original word lengths.

## Concepts Covered

- Opening and closing files
- Reading files using `read()`
- Writing files using `write()`
- File modes: `r` and `w`
- Using the `with open()` statement
- Searching for text in files
- Replacing file content using `replace()`
- Updating existing file data
- Generating and writing multiple files
- Working with loops and lists in File I/O

## Learning Outcome

Practiced reading, writing, searching, modifying, and updating text files using Python File I/O.
