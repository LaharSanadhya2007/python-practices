# Project 2: Python Mini Programs 🎮

A collection of simple Python mini programs created to practice basic Python concepts, the `random` module, loops, conditional statements, arithmetic operations, and user input.

## Programs

### 1. Number Guessing Game 🎯

The computer randomly selects a number between 1 and 10, and the player tries to guess the correct number.

**Concepts Used:**
- `random.randint()`
- User input
- Conditional statements
- Variables

### 2. Random Dice 🎲

Simulates rolling a dice by randomly generating a number between 1 and 6.

**Concepts Used:**
- Python `random` module
- `random.randint()`
- Variables

### 3. Password Generator 🔐

Generates a random 8-character password using letters and numbers.

**Concepts Used:**
- `random.choice()`
- Strings
- `for` loops
- Variables
- String concatenation

### 4. Simple Calculator 🧮

A basic calculator that performs mathematical operations based on the user's choice.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

**Concepts Used:**
- User input
- Type conversion (`int()` / `float()`)
- Conditional statements (`if-elif-else`)
- Arithmetic operators
- Variables
